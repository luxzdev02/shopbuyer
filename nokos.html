Syarat & Ketentuan

1. Tentang Layanan

FNB NOKOS OTP menyediakan layanan penyewaan nomor virtual untuk menerima kode verifikasi (OTP) dari berbagai aplikasi yang didukung. Kami hanya bertindak sebagai penyedia nomor virtual dan tidak memiliki hubungan dengan aplikasi pihak ketiga.

2. Ketentuan Akun

  • Setiap pengguna wajib mendaftar akun.
  • Pengguna bertanggung jawab atas keamanan akun dan password.
  • Dilarang membagikan API Key kepada pihak lain.
  • Aktivitas yang dilakukan menggunakan akun menjadi tanggung jawab pemilik akun.

3. Saldo & Deposit

  • Deposit yang telah berhasil masuk tidak dapat dikembalikan (Non Refundable).
  • Pastikan nominal deposit sesuai.
  • Kesalahan transfer akibat kelalaian pengguna bukan tanggung jawab FNB NOKOS OTP.
  • Deposit otomatis akan diproses apabila pembayaran berhasil terverifikasi.

4. Pemesanan Nomor

  • Nomor hanya berlaku untuk satu transaksi sesuai layanan yang dipilih.
  • Masa aktif nomor mengikuti timer pada website.
  • Nomor yang telah dibeli tidak dapat diganti kecuali sistem gagal memberikan layanan.
  • Harga layanan dapat berubah sewaktu-waktu.

5. Refund

Refund hanya diberikan apabila:

  • Nomor gagal menerima OTP.
  • Nomor dibatalkan oleh sistem.
  • Provider mengalami gangguan sebelum OTP diterima.

Refund tidak berlaku apabila:

  • Pengguna salah memilih negara/operator.
  • Pengguna membatalkan pesanan sendiri.
  • OTP sudah berhasil diterima.
  • Akun tujuan meminta verifikasi tambahan selain SMS.

6. Penggunaan API

  • API hanya boleh digunakan untuk kebutuhan yang sah.
  • Dilarang melakukan spam request.
  • Dilarang menyebarkan API Key.
  • Gunakan fitur Whitelist IP agar API lebih aman.
  • Penyalahgunaan API dapat menyebabkan API dinonaktifkan.

7. Larangan

Pengguna dilarang menggunakan layanan untuk:

  • Penipuan.
  • Spam.
  • Aktivitas ilegal.
  • Penyalahgunaan identitas.
  • Pelanggaran hukum yang berlaku.

Pelanggaran dapat mengakibatkan akun diblokir permanen tanpa pengembalian saldo.

8. Ketersediaan Layanan

FNB NOKOS OTP berusaha menjaga uptime setinggi mungkin, namun tidak menjamin:

  • Semua layanan selalu tersedia.
  • Semua aplikasi selalu menerima nomor virtual.
  • Semua OTP pasti masuk tepat waktu.

Gangguan provider berada di luar kendali kami.

9. API Rate Limit

Untuk menjaga stabilitas server:

  • Request berlebihan dapat dibatasi.
  • Aktivitas mencurigakan akan diblokir sementara.
  • Abuse API dapat menyebabkan suspend akun.

10. Keamanan

Disarankan:

  • Aktifkan Whitelist IP.
  • Hubungkan akun Telegram agar mendapat notifikasi transaksi.
  • Jangan membagikan password maupun API Key.

11. Perubahan Harga

Harga layanan dapat berubah sewaktu-waktu mengikuti harga dari provider tanpa pemberitahuan sebelumnya.

12. Perubahan Ketentuan

FNB NOKOS OTP berhak mengubah syarat layanan kapan saja. Perubahan akan berlaku setelah dipublikasikan pada website.

13. Bantuan

Apabila mengalami kendala:

  • Hubungi Customer Service melalui Telegram.
  • Sertakan ID Pesanan agar proses pengecekan lebih cepat.

14. Disclaimer

Dengan menggunakan FNB NOKOS OTP, pengguna dianggap telah membaca, memahami, dan menyetujui seluruh syarat dan ketentuan yang berlaku. FNB NOKOS OTP tidak bertanggung jawab atas penyalahgunaan layanan oleh pengguna maupun pelanggaran terhadap ketentuan platform pihak ketiga.
